# Polski Trainer — CSV import: контракт и конвенции

Справка для будущих сессий: как готовить файлы импорта для приложения
`~/Documents/polski-trainer` (Vite + React + TS, словарь в `data/vocabulary.json`,
импорт через **Słownik → Import CSV**, есть preview перед записью).

## Формат

```csv
pl,ru,type,sets,example_pl,example_ru
```

| Колонка | Смысл | Заметки |
|---|---|---|
| `pl` | польское слово/фраза | ключ дедупликации: lowercase, без пунктуации, диакритика сохраняется (`żaba` ≠ `zaba`) |
| `ru` | русское значение | несколько вариантов через запятую — все засчитываются как верные |
| `type` | `word` / `phrase` | опционально, автоопределяется по наличию пробела |
| `sets` | набор(ы) | несколько через `\|`; по display-имени; неизвестное имя создаёт новый набор |
| `example_pl` | пример на польском | **макс. 8 słówek**, слово в естественной словоформе |
| `example_ru` | тот же пример по-русски | только парой с `example_pl`, иначе оба отбрасываются |

Обязательны только `pl` и `ru`. Кодировка UTF-8, стандартное CSV-квотирование.

## Правила авторинга

1. Предложения — максимум 8 слов, чем короче тем лучше.
2. Диакритика обязательна и точна (`ą ć ę ł ń ó ś ź ż`), без ASCII-фолдинга.
3. Русский — живой, не подстрочник: он служит промптом в двух из четырёх тренировок.
4. Размер набора ≈ 15–25 записей (дистракторы в multiple choice берутся из того же набора).
5. Уровень B1: конкретная, бытовая, частотная лексика.
6. Импорт **обогащает, не перезаписывает** — повторный импорт того же файла безопасен.

## Конвенция имён наборов

`Polski / Русский` — например `Zwierzęta / Животные`, `Moda / Мода`.
Исключение: тематические наборы-источники по имени источника, без перевода
(например `KnopkaVideos` — лексика из видео блогера Knopka).

Одно слово может входить в несколько наборов одновременно — источник + тема.
